1. Contradiction — does any statement in the document contradict a statement in one of its sources? Quote both, with the document's line and the source's file and line.
2. Unsupported claim — does the document state as fact anything that no source states? List each, with the line.
3. Stale pointer — does any pointer in the document (a path, a file, a section, a name) name something the sources show does not exist, has moved, or is named differently? List each, with the line and what the sources show.
4. Altered restatement — where the document restates a rule or definition of a source, does the restatement narrow, widen or change it? Quote both, with the lines.
5. Homeless fact — does the document rely on a fact whose home is none of its sources, so that no source could confirm or deny it? List each, with the line.
6. Omission — what exists in the referent listing that the document does not name? List each path, with the document section that should name it.
