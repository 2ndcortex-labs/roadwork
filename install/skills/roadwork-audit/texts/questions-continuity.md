1. Divergence — where the document and a counterpart state the same thing, do they differ in substance? Quote both, with the document's line and the counterpart's file and line.
2. Missing counterpart — does the document state something a counterpart must also carry and does not? List each, with the line and the counterpart.
3. Orphaned statement — does a counterpart state something about the document's subject that the document should carry and does not? List each, with the counterpart's file and line.
4. Naming — do the document and a counterpart name the same thing by different names, or give different orders where order matters? List each, with both lines.
5. Version — do the document and a counterpart reflect different states of the same thing, one amended and one not? List each, with the lines that show it.
